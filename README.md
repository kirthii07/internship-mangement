# Internship Management System

A full-stack web application designed to manage internships, built with **Spring Boot** for the backend and **React** for the frontend.

---

## 🚀 Features

* **Student & Admin Portals:** Role-based access for managing applications and approvals.
* **Internship Tracking:** Track status, deadlines, and submissions in real-time.
* **RESTful APIs:** Seamless communication between the React frontend and Spring Boot backend.

---

## 🛠 Tech Stack

**Frontend:**
* React.js
* HTML5 / CSS3 / JavaScript (ES6+)
* Axios (for API integration)

**Backend:**
* Java & Spring Boot
* Spring Data JPA / Hibernate
* Spring Security (JWT authentication)
* MySQL / PostgreSQL (Database)
